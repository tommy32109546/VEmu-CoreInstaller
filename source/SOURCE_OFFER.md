# Source offer for bundled KytyPS5 core

The bundled file `core/kytyps5_libretro.dll` includes GPL-licensed code from KytyPS5 and local modifications.

Upstream project: KytyPS5  
Upstream repository: https://github.com/KytyPS5/KytyPS5.git  
Exact upstream commit used: `2638b1b07613dc32a4708d2cd61a75711b84b6cf`

The complete corresponding source for the upstream commit is available from the upstream repository at the commit above.

The exact local modifications are included in this package as `source/MODIFICATIONS.patch`.

Build details are included in this package as `source/BUILD_INFO.txt`.

The KytyPS5 license is included as `licenses/KytyPS5-LICENSE.txt`.

This source offer is provided so the GPL requirements are met without shipping a large source archive, test binaries, or development artifacts inside the Thunderstore package.
